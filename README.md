# RESTful веб-сервис для управления экосистемой ресторанов
## Цель: улучшить навыки работы с маршрутизацией на самом низком уровне(middleware) 
> Суть: клиент может отправлять запросы на любой зарегистрированный в системе ресторан. У любого ресторана клиент может осмотреть меню, сделать заказ, посмотреть статус заказа, посмотреть описание, посмотреть контакты, посмотреть отзывы, добавить отзыв, добавить блюдо в меню, добавить описание, добавить контакты


## Технологический стек

| Компонент | Технология |
|-----------|-------------|
| **C#** | .NET 8  |
| **ORM** | Entity Framework Core (Linq, Migrations) |
| **Архитектура** | Чистый ASP.NET Core middleware |
| **Логирование** | Кастомный LoggingMiddleware + Serilog  |
| **Обработка исключений** | Кастомный ExceptionHandler для отлова всех исключений |
| **API стиль** | REST |
| **База данных** | MySql |

> Вся сквозная логика приложения вынесена в компоненты `InvokeAsync`. Демонстрирую глубокое понимание конвейера запросов
