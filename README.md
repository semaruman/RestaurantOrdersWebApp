<h1>Веб api для работы с ресторанами</h1>
<h4>Цель: улучшить навыки работы с маршрутизацией на самом низком уровне(middleware), научиться тестировать api с помощью postman</h4>
<p>Суть: клиент может отправлять запросы на любой зарегистрированный в системе ресторан. У любого ресторана клиент может осмотреть меню, сделать заказ, посмотреть статус заказа, посмотреть описание, посмотреть контакты, посмотреть отзывы, добавить отзыв, добавить блюдо в меню</p>
<p>База данных: MySql</p>
