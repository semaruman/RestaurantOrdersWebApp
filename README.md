# RESTful веб-сервис для управления экосистемой ресторанов
## Цель: улучшить навыки работы с маршрутизацией на самом низком уровне(middleware) 
> Суть: клиент может отправлять запросы на любой зарегистрированный в системе ресторан. У любого ресторана клиент может осмотреть меню, сделать заказ, посмотреть заказы, посмотреть описание, посмотреть контакты, посмотреть отзывы, добавить отзыв, добавить блюдо в меню, добавить описание, добавить контакты


## ✨ Возможности API

### Для клиентов:
- 🔍 **Просмотр ресторанов** - список всех заведений в системе
- 📋 **Просмотр меню** - детальный просмотр блюд каждого ресторана
- 🛒 **Создание заказов** - оформление заказа из доступных блюд
- 📊 **Существующие заказы** - отслеживание выполнения заказов
- 📝 **Описание контактов** - просмотр контактной информации
- ⭐ **Отзывы** - просмотр и добавление отзывов о ресторанах

### Для администраторов:
- **Добавление ресторанов**
- ➕ **Добавление блюд** - расширение меню ресторана
- ✏️ **Редактирование описания** - обновление информации о заведении
- 📞 **Управление контактами** - добавление/изменение контактных данных


## Технологический стек

| Компонент | Технология |
|-----------|-------------|
| **C#** | .NET 8  |
| **ORM** | Entity Framework Core (Linq, Migrations) |
| **Архитектура** | Чистый ASP.NET Core middleware |
| **Логирование** | Кастомный LoggingMiddleware + Serilog  |
| **Обработка исключений** | Кастомный ExceptionHandler для отлова всех исключений |
| **API стиль** | REST |
| **База данных** | MySql |
| **Хранение временных данных** | Cookie/Сессии для хранения корзины, заказов |
| **JavaScript** | Отправка запросов на сервер |
| **HTML + Bootstrap 5** | Фронтенд часть сайта |

> Вся сквозная логика приложения вынесена в компоненты `InvokeAsync`. Демонстрирую глубокое понимание конвейера запросов
